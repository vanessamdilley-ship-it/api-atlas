# API Atlas PWA v1

117 imported catalog records from the supplied v1.5 JSON. No live API verification performed during this build.

## Deploy free with GitHub Pages
1. Create a public GitHub repository.
2. Upload the **contents** of this folder to the repository root.
3. In repository Settings > Pages, select Deploy from a branch, `main`, `/ (root)`, then Save.
4. Open the published HTTPS address on iPhone Safari; Share > Add to Home Screen.

Features: responsive catalog, keyword search, category/pricing/auth/protocol/verification filters, profile details, 5-item comparison, JSON/CSV export, installable PWA, cached offline read after first successful online load.

Limitations: no backend, accounts, scheduled ingestion, live pricing verification or unsupported cost estimates. Browser downloads may vary on iOS. PWA service worker requires HTTPS. Catalog updates require replacing catalog.json and publishing a new release.
